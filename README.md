# 拼豆工坊网页版

打开网页即可在电脑与手机上使用，无需安装 Python 或桌面程序。照片只在当前浏览器中处理，不会上传到服务器。

网站地址：https://sylvan-pan.github.io/bead-studio-web/

## 功能

- 选择相册图片、电脑拖入新图；自动更新预览，并可恢复上一份作品。
- 小挂件、随身配饰、桌面摆件、大幅作品与自定义尺寸；5 mm / 2.6 mm 规格和预计尺寸。
- 固定比例裁剪（1:1、4:3、3:4、9:16、16:9）、框选主体抠图与保留 / 擦除修补画笔。
- 明暗、对比度、饱和度、局部增强、细节保留和动漫黑色描边。
- 五套真实品牌色卡，支持已有色号限制和自定义 CSV / JSON 色卡。
- 电脑滚轮 / 手机双指缩放，点选图例手修、擦除、撤销、重做与整色替换。
- 导出整张 SVG、PNG、可打印 HTML、备料 CSV 和可继续编辑的 JSON。每个有豆子的格子填实际颜色并标注品牌色号，右侧附图例与用量。

不同设备之间不会自动同步作品；保存 JSON 后可在另一台设备打开继续手修。


## 效果边界与浏览器

建议使用近期版本的 Chrome、Edge、Safari、Firefox。浏览器原生解码负责照片方向与色彩配置处理，工作画布按 sRGB 输出。HEIC 等格式取决于浏览器解码支持，不支持时可先转换为 JPEG / PNG。

抠图采用纯色背景连通识别与 OpenCV GrabCut，不是语义识别模型；复杂背景、头发和半透明对象可能需要画笔修补。增强无法恢复原图不存在的细节，描边可能遮挡细节，建议对照原图调整。

照片导入会在浏览器内缩至长边最多 1200 像素，抠图候选缩至最多 720 像素；网格上限 256×256。PNG 导出根据设备画布限制缩放；SVG 始终保留全部真实色号并支持任意放大。

## 开源来源

色卡：maxcleme/beadcolors，MIT，源版本及许可见 docs/assets/palette-source.json 和 docs/licenses/beadcolors-MIT.txt。

抠图组件：OpenCV.js 4.9.0，Apache-2.0，来自官方 docs.opencv.org，压缩资产与校验值见 docs/vendor/SOURCE.json。组件只在需要复杂背景抠图时加载。当前浏览器在本网站加载压缩组件；不支持解压接口的旧浏览器会尝试从 OpenCV 官方站点加载。

应用逻辑独立实现。照片像素不经 GitHub 或任何抠图 API 上传。
